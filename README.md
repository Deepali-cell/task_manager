# Task Management App

This is a simple task management application built to understand authentication flow and basic CRUD operations.

Users can create an account, manage their tasks, and perform basic operations like adding and deleting tasks.

---

## Tech Stack

- Next.js
- Prisma ORM
- PostgreSQL
- JWT Authentication
- Cookies (for session handling)

---

## Features

- User signup and login  
- JWT-based authentication  
- Session handling using cookies  
- Add and delete tasks  
- View personal tasks  

---

## What I Learned

- Implementing authentication using JWT  
- Managing sessions with cookies  
- Protecting routes  
- Handling user-specific data  
- Basic CRUD operations with Prisma  

---

## Project Purpose

This project was built to understand how authentication works in real applications and how user-specific data is handled securely.

---

## Note

This is a practice project focused on authentication and basic task management. It is not intended as a production-ready application.
